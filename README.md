# 游戏修改器

这是一个基于Go语言和Fyne GUI框架开发的游戏修改器，可以查询和修改游戏中的数值。

## 功能特性

- 查找并打开目标游戏进程
- 搜索游戏中的特定数值
- 修改内存中的数值
- 图形用户界面操作

## 技术栈

- Go 1.16+
- Fyne GUI框架
- Windows API（用于进程内存操作）

## 安装依赖

```bash
go mod tidy
```

## 运行程序

```bash
go run main.go
```

## 使用说明

1. 在"进程名称"输入框中输入目标游戏的进程名（例如：game.exe）
2. 点击"查找进程"按钮打开目标进程
3. 在"搜索值"输入框中输入要查找的数值
4. 点击"搜索值"按钮查找匹配的内存地址
5. 在"内存地址"输入框中输入要修改的地址（十六进制格式，如：0x12345678）
6. 在"新值"输入框中输入想要设置的新值
7. 点击"修改值"按钮完成修改

## 注意事项

- 本程序仅用于学习和研究目的
- 使用游戏修改器可能违反某些游戏的服务条款
- 请负责任地使用本工具
